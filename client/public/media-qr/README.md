# 官网媒体二维码

此目录使用仓库内的静态图片，避免 GitHub Pages 上无法访问开发环境的 `/manus-storage/` 代理。

当前使用以下二维码图片：

- `instagram.jpg`
- `xiaohongshu.jpg`
- `douyin.png`
- `tiktok.jpg`
- `whatsapp.png`
- `kakaotalk.png`
- `wechat-work.png`

抖音使用独立的 `douyin.png`，TikTok 继续使用 `tiktok.jpg`。

建议优先使用正方形图片并保留完整白边；现有非方形图片会完整缩放显示。页脚显示小图，点击后打开大图。
